Animation
---------
No third-party motion files are bundled. All body motion, gaze, blinking,
breathing and lip movement is generated procedurally at runtime by
src/components/companion/VrmAvatar.tsx.

Optional: drop VRM Animation files into public/avatar/anim/ (idle.vrma,
talk.vrma, happy.vrma, embarrassed.vrma, annoyed.vrma, sad.vrma,
thinking.vrma, wave.vrma, touch.vrma). They are loaded automatically when
present and blended over the procedural layer. Missing files are ignored.
Only add files whose own licence permits application use, modification and
redistribution, and record that licence in this file.

Replacing the character
-----------------------
Upload another .vrm and replace public/avatar/mirei.vrm.asset.json with the new
pointer (or set the URL in src/components/companion/VrmAvatar.tsx). No other
code change is required.
