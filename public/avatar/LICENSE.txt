  The model is loaded from the jsDelivr CDN instead of being committed to the

  deploy and inside the Android WebView.

Animation
---------
No third-party motion files are bundled. All body motion, gaze, blinking,
breathing and lip movement is generated procedurally at runtime by
src/components/companion/VrmAvatar.tsx.

Optional: drop VRM Animation files into public/avatar/anim/ (idle.vrma,
talk.vrma, happy.vrma, embarrassed.vrma, annoyed.vrma, sad.vrma,
thinking.vrma, wave.vrma, touch.vrma). Missing files are ignored. Only add
files whose own licence permits application use, modification and
redistribution, and record that licence here.

Replacing the character
-----------------------
Point VRM_MODEL_URL in src/components/companion/VrmAvatar.tsx at another .vrm
URL. No other code change is required.
