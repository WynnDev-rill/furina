# Audit Furina app — 17 November 2026

Repo: `WynnDev-rill/furina`, baseline `88a1958` pada `main`. Cakupan: app web Lovable terkini dan pemeriksaan statis launcher `webview-android/`. Riwayat Termux tidak diubah.

## Temuan dan perbaikan

| Temuan                                                                 | Dampak                                                                                                                            | Perbaikan                                                                                                                                                                        |
| ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

Jangan memanggil AI bila penyimpanan awal gagal.                                                           |

| Pembersihan akun hanya terjadi lewat tombol logout                     | Saat sesi habis atau akun berubah, isi akun lama masih dapat tampil sebagai data tamu, termasuk draf/kutipan                      | Pembersihan mengikuti perubahan identitas dan kepemilikan cache, termasuk sesi kedaluwarsa saat startup. | Parser event XTTS hanya menerima pemisah LF                            | Respons SSE yang sah dengan CRLF gagal dibaca sampai timeout                                                                      | Terima kedua pemisah LF dan CRLF.                                                                                                                                                |
| Versi transitif terkunci memiliki advisory keamanan                    | Risiko pada dependensi build/dev dan pemrosesan input sesuai advisory masing-masing                                               | Perbarui resolusi transitif dalam rentang yang diizinkan, pertahankan versi langsung framework dan aturan umur rilis 24 jam.                                                     |

Perubahan runtime berada di `src/routes/index.tsx`, `src/lib/message-status.ts`, dan `src/lib/furina.functions.ts`; pembaruan dependensi berada di `bun.lock`. Tidak ada perubahan skema atau penulisan data akun produksi.

## Verifikasi

- Instalasi Bun dengan `--frozen-lockfile` berhasil.
- Suite awal: 44/44 tes lolos. Suite akhir: 59/59 tes lolos melalui `node --test tests/*.test.mjs`.
- Tambahan 15 tes mencakup penyimpanan sebelum AI, kegagalan AI/database, pemulihan status, pemisahan akun, stream macet, pelepasan reader, dan CRLF. Bug yang diperbaiki direproduksi sebelum perbaikan. Handler asli dieksekusi dengan batas Supabase/provider terisolasi, tanpa akun produksi.
- `tsc --noEmit` lolos; `bun run build` lolos. Build masih mengeluarkan peringatan bundler dependency `use client` yang juga ada pada baseline.
- `bun run dev` berhasil; halaman `/` memberi HTTP 200 dan judul `Furina — AI Companion`.
- ESLint untuk helper dan semua file tes baru lolos. Lint seluruh repo masih gagal: 959 error dan 6 warning, terutama `prettier/prettier`, `no-empty`, warning export komponen, serta false positive hooks pada fungsi `useGeminiKeys` yang bukan React Hook. Jumlah masalah pada dua file runtime yang disentuh sama dengan baseline: 18 dan 289. Perbaikan format seluruh repo tidak dicampurkan ke patch bug ini.
- Audit dependensi awal: 33 advisory pada 11 nama paket (22 high, 9 moderate, 2 low). Pemindaian terakhir: satu moderate pada `minimatch@10.2.6`, [GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249). Jalurnya adalah `typescript-eslint` → `typescript-estree` → `minimatch`; batas dependency upstream masih `^10.2.2`, sementara perbaikannya berada di major 11. Tidak memaksakan override lint lintas major.
- Review kode terpisah menemukan kasus status pesan yang gagal diperbarui setelah jawaban berhasil disimpan; kasus ini sudah ditangani helper pemulihan dan tes regresi.

## Batas dan tindak lanjut

- APK tidak dibuild/dijalankan ulang: Gradle dan Android SDK tidak tersedia di environment. OAuth pada perangkat Android, keyboard, pemilihan berkas, dan perpindahan browser/WebView memerlukan pengujian perangkat.
- Tidak menguji login Google nyata, pemanggilan AI/TTS berbayar, konfigurasi RLS yang terpasang, atau migrasi database produksi. Pemeriksaan kode tidak membuktikan keadaan server produksi.
- Belum menguji urutan effect React melalui browser untuk pergantian akun; tes menguji callback dan fungsi penyimpanan asli secara terisolasi.
- Jika penyimpanan balasan gagal, peringatan meminta pengguna menyimpan salinan sebelum muat ulang. Patch ini belum menambahkan antrean sinkronisasi offline otomatis.
- Pemulihan status memakai urutan pesan; sapaan proaktif yang kebetulan langsung menyusul pesan tertunda dapat dianggap sebagai balasan. Pengaitan turn eksplisit dibutuhkan untuk menghilangkan ambiguitas ini sepenuhnya.
- Perubahan disiapkan melalui PR; publikasi produksi tetap melalui Lovable sesuai instruksi repo. Situs dan APK produksi belum diperbarui oleh audit ini.
