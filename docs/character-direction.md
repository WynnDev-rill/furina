# Provisional original character direction

The reference image is used only for broad mood: soft pink hair, warm knitwear, gentle expression, and an elegant anime-inspired presentation.

The final character will use an original face, hair silhouette, eye design, accessories, clothing construction, color distribution, name, and identity. No franchise lore or recognizable costume elements will be reproduced.

Provisional identity: **Mirei**.

Core personality: proud, expressive, realistically tsundere, quietly attentive, capable of disagreement, never cruel or possessive.
