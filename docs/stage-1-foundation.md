# Stage 1 foundation checkpoint

The branch now contains the online 3D companion foundation. CI must pass before this stage is considered complete.

Validation targets:

- Web production build.
- React Three Fiber scene compilation.
- AI Horde provider module compilation.
- Android debug APK build.
- Internet and microphone permissions present in the APK.

The branch must not merge to `main` until both web and Android validation succeed.
